# 拼音使用说明

[English](pinyin.md) | 简体中文 · [基础使用](../README.zh-CN.md)

拼音引擎不是开箱即用的输入法。项目仅附带单字表，日常使用前需要[自行导入词组库](#添加拼音词库)。

## 开始输入

在设置中启用「中文拼音」，按 `Ctrl+Space` 切换到它，然后输入小写拼音。
支持全拼、简拼、全拼与简拼混输，以及最后一个音节的前缀补全。
例如 `shurufa`、`srf`、`shurf` 可以查询读音对应的词；实际结果取决于已加载词库。

| 按键 | 行为 |
| --- | --- |
| Space | 提交当前选中候选 |
| Enter | 提交原始输入，不是确认候选 |
| 1–9 | 选择当前页相应候选 |
| `-` / `=`、PageUp / PageDown | 上一页 / 下一页 |
| 方向键、Home / End | 移动候选选中项 |
| Backspace | 删除输入 |
| Esc | 取消当前输入 |
| Ctrl+. | 切换中文／ASCII 标点，保留当前输入 |
| Ctrl+Shift+P | 有候选时打开场景列表，可在拼音设置中修改 |

鼠标点击也可选词。翻页不会产生学习记录；切换输入法会取消尚未提交的组合。

输入 `v` 表示 `ü`，例如 `nv`。单引号用于明确音节边界，如 `xi'an`。
由单引号结束的片段，若有对应完整音节单字，则按该单字音节匹配，不在片段内部继续拆分。
单引号是拼音输入的一部分，不会被非拼音扩展忽略。

## 设置

通过 `mirix-panel --settings` 选择中文拼音：

- **场景**：选择当前词库与学习环境。
- **候选拼音显示**：开关读音注释，不影响匹配或学习。
- **标点**：选择中文或 ASCII 标点，也可用 Ctrl+.。
- **场景管理**：创建、重命名、复制、归档。
- **场景菜单快捷键**：修改本引擎的列表快捷键。
- **重新加载词库**：使文件修改生效。
- **个人词条**：管理个人添加、学习和偏好。

候选注音使用小写字母，音节间以空格分隔，例如 `你好 [ni hao]`、`女 [nv]`。
显示开关保存在拼音配置目录的
`config.toml` 中，字段为 `show_reading`；一般直接使用界面即可。

中文标点模式下，有候选时输入标点会一起提交当前候选和标点。
组词中的单引号仍用于分音，`-` / `=` 仍用于翻页；
连续数字后的点号透传，方便输入小数。标点模式跨场景保存。

## 文件位置

默认配置目录是 `~/.config/mirix/input-methods/pinyin/`，
数据目录是 `~/.local/share/mirix/input-method-data/pinyin/`。
分别遵循 XDG_CONFIG_HOME 和 XDG_DATA_HOME；安装目录中的 engine 不是存放个人数据的位置。

```text
配置目录/
├── config.toml
├── characters.tsv
├── dictionaries/                  # 所有场景共享的词组
├── extensions/                    # 所有场景共享的扩展
│   ├── exact.tsv
│   └── completion.tsv
└── profiles/<场景>/
    ├── dictionaries/              # 仅该场景启用
    └── extensions/
        ├── exact.tsv
        └── completion.tsv

数据目录/
├── active-profile.json
├── profile-shortcut.json
├── punctuation-mode.json
└── profiles/<场景>/
    ├── learning.json
    └── vocabulary.json
```

首次启动补齐默认单字表和缺失的空扩展文件，不覆盖已有内容。
重装程序不需要删除这些目录。备份应同时包含配置和数据；复制学习数据前先正常退出 Mirix。

## 添加拼音词库

### 单字表

`characters.tsv` 每行三列，可用空格或 Tab 分隔：

```text
# 汉字 输入拼音 权重
闺 gui 38845
女 nv 30000
```

拼音使用完整的小写字母单音节（`ü` 写作 `v`），权重为非负整数。已有单字文件不会被程序升级覆盖。

### 词组表

在 `dictionaries/` 下创建 UTF-8 的 `.tsv` 文件。
每行使用真正的 Tab 分隔「输入拼音、完整展示拼音、文字、可选权重」：

```text
shurufa	shū rù fǎ	输入法	1000
chengxu	chéng xù	程序	800
```

上例列间为 Tab；不要把用于展示读音内部的空格当成列分隔。
输入键去掉分隔符后，必须与展示拼音去声调、`ü` 转 `v` 的结果一致。
展示读音必须给出完整音节，不能用简拼代替；简拼查询由引擎自动处理。

单字和词组文件都允许空行及以 `#` 开头的注释。
词组权重可省略，默认 0；同文字同读音重复出现时取最高权重。
权重是相对排序数值，不保证高权重词跨越更准确的匹配结果。
场景专属词组放入 `profiles/<场景>/dictionaries/`，格式相同。

保存后点击「重新加载词库」。无需重新编译，也不用修改安装注册表。

## 自定义映射、补全与 Emoji

扩展文件不要求输入键是合法拼音，但必须由小写 ASCII 字母组成。
格式为 `输入键 输出内容 [权重]`，用空格或 Tab 等空白分隔；权重默认为 0。

`extensions/exact.tsv` 只有完整输入键才命中：

```text
addr "Room 12, Main Street" 100
smile 😊 100
xiaolian 😊 100
```

`extensions/completion.tsv` 支持连续前缀和完整命中：

```text
google Google 1000
good good 800
smile 😊 100
```

输出可为文字、英文或 Emoji；含空格时使用双引号，转义遵循 JSON 字符串规则。
不同关键词可以对应相同输出。支持空行和 `#` 注释。

共享扩展与当前场景扩展同时生效。修改后同样需要「重新加载词库」。
扩展只在拼音模式中查询，不接管英文键盘，也不使用 `:smile:` 触发语法。

扩展与拼音共同排序：完整命中优先于前缀补全，前缀补全优先于简拼；
同类优先已有词条，再考虑补全距离。扩展同等匹配时比较权重，最终按输出去重。
扩展提交不写入拼音学习统计。

## 场景管理

首次运行创建名为「日常」的场景。场景是拼音内部的词库和学习环境，不是新的输入法。

- **新建**：输入名称并创建，立即切换；共享词库仍可用，专属数据为空。成功后清空名称框。
- **重命名**：保留该场景的全部内容。
- **复制**：复制词库、扩展、个人词条和学习记录，之后各自独立积累。
- **归档**：从活动列表移除，文件移到配置和数据目录各自的
  `archived-profiles/<名称>-<时间戳>`；不永久删除，至少保留一个活动场景。

名称允许中文和空格，不允许空名称、路径分隔符、控制字符、`.` 或 `..`，同名目录不覆盖。
大场景复制可能耗时，当前引擎会等待；配置交换限时 10 秒。

切换场景保留正在输入的拼音，重新查询候选并清除短上下文，选择会保存到下次启动。
重复选择当前场景不改变输入。不会根据应用自动切换。
手动创建新场景目录后需要重启发现；「重新加载词库」只更新已加载场景。
恢复归档时先退出引擎，再将同一归档的配置和数据分别放回各自的 `profiles/<场景>/`。

## 个人词条与学习

选词提交时自动学习；浏览、翻页、取消和 Enter 提交原文不学习。
学习按场景隔离，结合重复选择、近期程度和同一输入会话的短上下文影响排序。
一次选择不会永久置顶；失焦、取消或切换场景后，不把旧会话上下文继续串接。
引擎不读取应用全文来推断上下文。

在设置中选择中文拼音，打开「个人词条」。
可按文字或读音搜索、翻页浏览，也可填写词条及完整读音后添加。
拼音引擎需要已加载，但无需切换当前输入法。

文字和完整读音共同识别词条，读音可带调或无调，音节间用空格分隔，例如 `shū rù fǎ`。

支持搜索、添加、置顶／取消置顶、隐藏／显示、忘记学习、移除词条。

操作绑定页面读取的场景。切换场景后重新打开词条页面；
过期操作会报错，不会写入另一个场景。

修改立即作用于内存，后台保存。
正常退出会等待保存；失败保留待写数据并重试，设置页可显示错误和手动重试入口。
强制终止可能丢失最新操作；不要在运行时手动编辑 learning.json 或 vocabulary.json。

## 排查

| 现象 | 检查 |
| --- | --- |
| 词组缺失或长句结果差 | 是否添加了词组库，而不只是默认单字表；读音是否完整准确 |
| 文件修改没有生效 | 是否点击了「重新加载词库」；新场景目录需要重启 |
| 扩展不出现 | 是否处于拼音模式、键是否小写、exact 是否完整命中、文件是否位于当前配置／场景 |
| 重载失败 | 查看错误中的文件与行号，检查 Tab、读音、权重和引号；失败时仍使用原词库 |
| 删除个人词后仍出现 | 移除词条不删除基础词库；需要屏蔽时使用「隐藏」 |
| 编辑期间切换了场景 | 确认当前场景，重新打开词条页面 |
| 提示保存失败 | 检查空间、权限和数据目录是否被另一个实例占用，处理后重试保存 |

重新加载会同时校验单字、共享词组与扩展，以及所有已加载场景的词组与扩展；
全部成功才替换，保留当前输入与学习，原选中词仍存在时继续选中它。
日志可用 `journalctl --user -u mirix.service -f` 查看。
